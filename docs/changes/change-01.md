# ЗНИ-01: Добавить онлайн-отмену записи

**Автор:** Стихарь А.
**Дата:** 2026-11-18
**Статус:** Принята
**Связанная история:** Issue #2 «[Must] Отмена записи»

## 1. Описание изменения
Добавить студенту возможность отменять созданную запись на приём онлайн,
не позднее чем за 24 часа до начала приёма.

## 2. Причина изменения
По результатам интервью со студентами: сейчас отменить запись можно только
звонком или личным визитом в регистратуру. Из-за этого растёт доля неявок
без предупреждения, а регистраторы тратят время на ручную отмену.

## 3. Оценка влияния

| Параметр | Влияние |
|---|---|
| Срок | +8 часов работы (API отмены + кнопка в интерфейсе + тесты) |
| Бюджет | В пределах буфера 25%, заложенного в ЛР-3 (WBS-3.2) |
| Архитектура | Новый эндпоинт `DELETE /appointments/{id}`; статус талона возвращается в «свободен» |
| Риски | Низкие: логика обратна уже существующей записи |

## 4. Решение
**Принята.** Изменение включено в бэклог с приоритетом Must и запланировано
в спринт вместе с базовым сценарием записи.

**Решение принял:** владелец продукта Стихарь А.
