# CR-1: Лимит активных записей для студента

**Описание:** Ограничить число активных записей одного студента двумя.
**Причина:** Студенты записываются к нескольким врачам «на всякий случай» и не приходят, из-за чего растёт доля неявок.
**Влияние:** +3 часа на модуль записи, +2 теста. Срок ЛР-6 не сдвигает.
**Решение:** Принято (Владелец продукта — Стихарь А., 25.11.2026).
