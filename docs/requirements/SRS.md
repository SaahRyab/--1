# SRS — ИС «Запись к врачу»

## Функциональные требования

ФТ-1. Система должна авторизовывать студента по университетской учётной записи.
ФТ-2. Система должна проверять прикрепление студента к студенческой поликлинике.
ФТ-3. Система должна показывать расписание врачей с фильтром по специальности и дате.
ФТ-4. Система должна отображать только свободные талоны в расписании.
ФТ-5. Система должна позволять студенту записаться на индивидуальный приём при наличии свободного талона.
ФТ-6. Система должна позволять студенту перенести запись на другой свободный талон.
ФТ-7. Система должна позволять студенту отменить запись не позднее чем за 2 часа до приёма.
ФТ-8. Система должна формировать лист ожидания при отсутствии свободных талонов.
ФТ-9. Система должна позволять регистратору создавать групповую запись студентов на диспансеризацию.
ФТ-10. Система должна отправлять студенту напоминание о приёме за 24 часа.
ФТ-11. Система должна уведомлять студента о переносе или отмене приёма со стороны поликлиники.
ФТ-12. Система должна фиксировать статус талона (свободен / занят / отменён / неявка).
ФТ-13. Система должна показывать регистратору список записей на день.
ФТ-14. Система должна формировать отчёт заведующему по неявкам за период.
ФТ-15. Система должна запрещать запись студенту без прикрепления (с пояснением причины).
