# Протокол выбора базовой модели

## Рассмотренные варианты
- Рябкова А. — UC-модель + диаграмма классов «Студенческая поликлиника».
- Стихарь А. — UC-модель + диаграмма классов «Фитнес-клуб».

## Выбранная база
Модель Рябковой А. (поликлиника).

## Аргументы
1. Полнота: покрывает 5 из 5 Must-историй ЛР-4; у фитнес-клуба — 3 из 5.
2. Наличие include/extend: проверка прикрепления вынесена в include.
3. Социальная значимость и потенциал интеграции с ИС университета.

## Заимствования из альтернативы
Из модели Стихарь А. взята сущность «Слот» с явной кратностью 1..1 к Записи.

## Пометка
Модели приняты из ПИС (не план Б).
