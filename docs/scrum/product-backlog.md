# Бэклог продукта (симуляция) с оценками

Оценки выставлены покером планирования: каждый участник одновременно показывал карту из ряда Фибоначчи (1, 2, 3, 5, 8, 13). Расхождения обсуждались до сближения.

| ID | История | Оценка (SP) | Приоритет (MoSCoW) | Критерий готовности (DoD) |
|---|---|---|---|---|
| Б-1 | Авторизация студента и проверка прикрепления | 5 | Must | Студент входит по учётке вуза; система показывает статус прикрепления |
| Б-2 | Просмотр расписания врачей и свободных талонов | 8 | Must | Отображается сетка «врач × дата × время», занятые слоты недоступны |
| Б-3 | Онлайн-запись на индивидуальный приём | 8 | Must | Студент выбирает врача → дату → время → подтверждает; запись сохраняется |
| Б-4 | Отмена записи | 2 | Must | Студент отменяет свою запись; слот снова свободен |
| Б-5 | Перенос записи | 3 | Should | Студент меняет дату/время без потери истории |
| Б-6 | Групповая запись на диспансеризацию | 13 | Should | Регистратор создаёт поток; студенты записываются в свободные окна |
| Б-7 | Напоминания о приёме | 5 | Could | За N часов до приёма студент получает уведомление |
| Б-8 | Уведомления о переносе/отмене | 5 | Could | При изменении приёма студент получает уведомление |
| Б-9 | Кабинет регистратора | 8 | Should | Регистратор видит все записи, может переносить/отменять |
| Б-10 | Кабинет врача | 8 | Could | Врач видит расписание своих приёмов |
| Б-11 | Информация о поликлинике (адрес, график, справки) | 3 | Could | Статическая страница с контактами и графиком |
| Б-12 | Экспорт записи в календарь | 5 | Won't (эта версия) | — |
