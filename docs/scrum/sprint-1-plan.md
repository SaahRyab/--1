# Планирование спринта 1 (игровой)

**Цель спринта:** студент может записаться к врачу и отменить запись.

**Выбрано историй:** Б-1 (5) + Б-3 (8) + Б-4 (2) = **15 SP** (ориентир — возможности команды на первый спринт).

**Декомпозиция на задачи:**
- [ ] Б-1: экран входа, проверка прикрепления, заглушка API
- [ ] Б-3: экран выбора врача, календарь слотов, подтверждение, сохранение записи
- [ ] Б-4: кнопка отмены, освобождение слота

**Definition of Done:** история работает в демо-режиме, критерий приёмки выполнен, PO принял на обзоре.

**События игровых «дней» (вводил преподаватель):**
- День 1: срочная история от заказчика (Б-7 «Напоминания») — **в спринт не взята**, ушла в бэклог решением PO.
- День 2: отсутствие участника — задачи перераспределены, SM зафиксировал риск.
