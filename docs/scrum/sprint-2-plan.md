# Планирование спринта 2 (игровой)

**Цель спринта:** регистратор видит записи и может переносить их.

**Ориентир по velocity:** ~14–15 SP (по спринту 1).

**Выбрано историй:** Б-5 (3) + Б-9 (8) + Б-11 (3) = **14 SP**.

**Декомпозиция:**
- [ ] Б-5: экран переноса, проверка свободного слота
- [ ] Б-9: список записей, фильтры, действия переноса/отмены
- [ ] Б-11: страница с адресом и графиком

**События «дней»:**
- День 1: обнаружен дефект в Б-3 (двойная запись на слот) — заведена задача, исправлена.
- День 2: срочная история от заказчика (Б-8 «Уведомления») — **в бэклог**, не в спринт.
